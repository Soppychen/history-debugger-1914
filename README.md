# 历史现场调试器：1914 低保真原型

这是一个 React + TypeScript + Vite 的最小可运行原型，用于验证《历史现场调试器：1914》的核心循环。

## 已接入数据

原型从 `public/data` 读取以下 JSON：

- `variables_1914.json`
- `timeline_1914.json`
- `intervention_cards_1914.json`
- `intel_cards_1914.json`
- `endings_1914.json`

这些文件来自项目内的两个资料文件夹：

- `history_debugger_1914_json_pack`
- `history_debugger_1914_timeline_and_specs`

## 启动方式

先安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

浏览器打开终端显示的本地地址，通常是：

```txt
http://localhost:5173
```

## 测试与验证

运行数据验证：

```bash
npm run validate:data
```

运行完整基础测试：

```bash
npm test
```

`npm test` 会先检查五个 JSON 是否能读取，再验证变量引用、卡牌 `requirements`、`effects`、`risks`、12 个 timeline 回合推进、ending 条件触发，最后执行一次生产构建。

## 当前实现

- 初始化 `turn=1`、`AP=2`，变量使用 JSON 中的 `initialValue`。
- 显示当前回合、日期、AP、全面战争概率和风险状态。
- 显示 12 个变量数值条。
- 显示 12 回合时间线，并高亮当前回合。
- 显示当前回合推荐情报卡。
- 显示当前可用干预卡。
- 用卡时检查 AP、回合范围和 `requirements`。
- 用卡后扣除 AP，应用 `effects`，检查并应用 `risks`，记录 `actionLog`。
- 推进回合时应用当前回合 `defaultPressure` 和满足条件的 `specialRules`。
- 第 12 回合后或触发全面战争条件时，根据 `endings_1914.json` 判定结局。
- 结局报告可重新开始。
- 干预卡会显示锁定原因，AP 不足时置灰。
- 用卡或推进回合后，会高亮发生变化的变量并显示本次 delta。
- 顶部和结算报告中都可以导出当前 `GameState` JSON 便于调试。
- 新增匿名玩家身份、恢复编码、本地模拟存档和匿名行为分析接入层：
  - 首次进入会自动生成 `HD-XXXX-XXXX-XXXX-XXXX` 玩家编码。
  - 同一浏览器会自动识别玩家，可用编码恢复本地模拟身份。
  - 支持 3 个自动滚动存档、5 个手动存档位和结局归档。
  - 隐私弹窗允许玩家只保留必要数据，或选择开启匿名玩法分析。
  - 当前实现使用 `localStorage` 模拟未来后端 API，不会上传服务器。
- 管理员分析后台为隐藏页面，试玩时可访问：

```txt
http://localhost:5173/#admin
```

后台显示玩家数、会话数、存档数、事件分布、卡牌使用、结局分布、玩家风格均值和最近事件。普通玩家界面没有入口。
- 根据 `AUDIO_CUE_GUIDE.md` 接入了动态配乐和基础音效：
  - 低压/早期阶段播放《战壕的黎明》。
  - 动员、战争迫近、不可逆节点或 WAR 进入高危时切到《钢铁洪流》。
  - 战争/失败类结局切到《无名战士》，和平/冻结类结局切到《历史的回响》。
  - 情报、卡牌、变量变化、风险反噬、推进时间、不可逆锁定、结局报告会播放对应音效。
  - 顶部下方提供音乐/音效开关、音量滑杆和“启用音频”按钮，设置会写入 `localStorage`。

## 手动测试路线

每回合可以先点击当前情报卡查看详情，再按下面的卡牌顺序用卡；未列出的回合可以直接推进。

### 路线 A：走向全面战争

目标结局：`E01 全面战争`

操作：

1. 不使用任何干预卡。
2. 从第 1 回合连续点击“推进回合”到第 12 回合。
3. 预期：全面战争概率升至高位，最终触发 `E01`。

### 路线 B：走向巴尔干局部战争

目标结局：`E03 巴尔干局部战争`

用卡顺序：

T3: C11, C12
T4: C14, C15
T5: C16
T6: C21
T7: C22
T8: C23
T9: C28
T10: C30

验证重点：俄国动员压力被压低，联盟锁定没有进入全面战争阈值，但奥匈强硬度仍足以形成局部战争。

## 已知问题

- 这是低保真规则原型，卡牌推荐、情报阅读和卡牌解锁还没有做成严格教学流程；当前更偏调试沙盘。
- 干预卡目前按“本局一次性使用”处理，尚未区分可重复政策与一次性事件。
- 结局和路线已经能跑通，但数值平衡仍是 Demo 级别，后续需要根据试玩反馈继续调。
- 目前没有浏览器端自动化点击测试；基础测试集中在 JSON、规则执行和构建。
- 玩家账户、存档和分析后台目前是前端本地模拟层，换浏览器或清理 `localStorage` 后数据会消失；未来接真实后端时应替换 `src/auth`、`src/save`、`src/analytics` 中的 client。
- 恢复编码在本地 mock 中会保留一份用于显示；真实后端版本应只保存 hash，并只在创建时返回明文编码。
- 浏览器要求用户首次点击或按键后才能播放音频；如果没有声音，先点击“启用音频”。
- 作曲家提供的多个音效合集目前按静音间隔配置了初始切片时间码，后续拿到精确 cue sheet 后，只需更新 `src/audio/audioConfig.ts`。
- 音频素材当前实际文件名是下划线 `.wav`，路径位于 `public/assets/audio/music/`，与 `AUDIO_CUE_GUIDE.md` 中的推荐 `.mp3` 命名不同。
